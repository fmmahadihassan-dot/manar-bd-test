# Manar BD – ডাইনামিক ওয়েবসাইট

সাইন আপ / লগইন, কাস্টমারের প্রোফাইল ও অর্ডার ইতিহাস, অ্যাডমিন প্যানেল (পণ্য, ব্যানার, অর্ডার, অফার, ইউজার) সহ পূর্ণ দোকান।
কোনো বাইরের প্যাকেজ বা `npm install` লাগে না।

## ১) নিজের ফোন বা কম্পিউটারে চালিয়ে দেখা

দরকার: **Node.js ভার্সন 22 বা তার বেশি** (`node -v` দিয়ে দেখুন)। Termux এ: `pkg install nodejs`

```
cd manar-dynamic        # এই ফোল্ডারে ঢুকুন
node server/dev.js      # সার্ভার চালু
```

- সাইট: http://localhost:8080
- অ্যাডমিন প্যানেল: http://localhost:8080/admin/
- **প্রথম যে অ্যাকাউন্ট খুলবেন সেটাই মালিক (Owner) হবে।** তাই নিজে প্রথমে সাইন আপ করুন।
- সব তথ্য (পণ্য, অর্ডার, ইউজার) থাকে `data/manar.db` ফাইলে। ফাইলটা মুছে দিলে সব নতুন করে শুরু হয়।
- পোর্ট বদলাতে: `PORT=3000 node server/dev.js`

## ২) অ্যাডমিন প্যানেলে কে ঢুকতে পারবে

- আলাদা ইউজারনেম বা পাসওয়ার্ড নেই। কাস্টমার যে অ্যাকাউন্টে লগইন করে, অ্যাডমিনও সেই একই লগইন ব্যবহার করে।
- পার্থক্য হলো অ্যাকাউন্টের **ভূমিকা (role)**: `customer`, `admin` বা `owner`।
- কেউ `/admin/` ঠিকানা লিখে ঢুকতে চাইলে, সে অ্যাডমিন না হলে "No admin access" দেখবে। সার্ভারও প্রতিটা অ্যাডমিন কাজ আলাদা করে যাচাই করে, তাই কোড ঘেঁটেও ঢোকা যায় না।
- **Owner** (আপনি): সব পারবেন, আর অন্যকে অ্যাডমিন বানানো/সরানো ও কারও পাসওয়ার্ড রিসেট করা শুধু আপনিই পারবেন।
- **Admin** (আপনার লোক): পণ্য, ব্যানার, অর্ডার, অফার সামলাবে, কিন্তু ইউজার বা অ্যাডমিন বদলাতে পারবে না।
- নতুন অ্যাডমিন বানাতে: ওই ব্যক্তি আগে সাইটে সাধারণ সাইন আপ করবে। তারপর আপনি অ্যাডমিন প্যানেলের **Users** ট্যাবে গিয়ে "Make admin" চাপবেন।

## ৩) Cloudflare এ ফ্রিতে চালু করা

**গুরুত্বপূর্ণ:** Cloudflare এ জিপ ফাইল আপলোড (Direct Upload) দিলে শুধু স্ট্যাটিক ফাইল ওঠে, `functions` ফোল্ডার (ব্যাকএন্ড) ওঠে না। তাই GitHub দিয়ে করতে হবে। আপনার জিপ আপলোডে স্ক্রিন লাফানোর সমস্যাও এতে এড়ানো যাবে।

### ধাপ ১: GitHub এ কোড তোলা
1. github.com এ একটা নতুন রিপোজিটরি বানান (যেমন `manar-bd`)।
2. এই ফোল্ডারের সব কিছু (`functions`, `public`, `server`, `package.json` ...) রিপোজিটরিতে আপলোড করুন। `data` ফোল্ডার তুলবেন না।
   (কম্পিউটার থেকে GitHub এর "Add file → Upload files" এ ফোল্ডার টেনে ফেলা সবচেয়ে সহজ।)

### ধাপ ২: ডাটাবেস বানানো (D1)
1. Cloudflare Dashboard → **Storage & databases → D1 SQL database → Create**
2. নাম দিন `manar-db`। টেবিল নিজে নিজেই তৈরি হয়ে যাবে, আলাদা কিছু চালাতে হবে না।

### ধাপ ৩: সাইট চালু (Pages)
1. **Workers & Pages → Create → Pages → Connect to Git** → আপনার রিপোজিটরি বাছুন।
2. Build settings:
   - Framework preset: **None**
   - Build command: **খালি রাখুন**
   - Build output directory: **`public`**
3. Deploy চাপুন।

### ধাপ ৪: ডাটাবেস ও মালিক যুক্ত করা
Pages প্রজেক্টে ঢুকে **Settings** এ:
1. **Bindings → Add → D1 database**: Variable name লিখুন `DB` (বড় হাতের), ডাটাবেস বাছুন `manar-db`।
2. **Variables and Secrets → Add**: নাম `OWNER_LOGIN`, মান আপনার ইমেইল বা মোবাইল নম্বর (যেমন `you@gmail.com`)।
   এই ইমেইল/নম্বর দিয়ে সাইন আপ করলেই আপনি Owner হবেন। কেউ আগে সাইন আপ করলেও Owner হবে না।
3. Production এর জন্য দুটোই দিন, তারপর **Deployments → Retry deployment** (বা নতুন করে Deploy) দিন।

### ধাপ ৫: নিজের ডোমেন
**Custom domains → Set up a domain**। ডোমেন Cloudflare থেকে কিনলে সবচেয়ে সহজ (`.com` প্রায় ১,২০০ থেকে ১,৮০০ টাকা বছরে)।

### ধাপ ৬: প্রথম ব্যবহার
1. আপনার সাইটে গিয়ে `OWNER_LOGIN` এর ইমেইল/নম্বর দিয়ে সাইন আপ করুন।
2. `আপনার-ডোমেন/admin/` এ গিয়ে পণ্য, ব্যানার, অফার ঠিক করুন।
3. শুরুতে ১৬টা নমুনা পণ্য থাকে। ইচ্ছামতো মুছে বা বদলে নিন।

## ৪) এখন কী কোথায় বদলাবেন

| কী | কোথায় |
|---|---|
| পণ্য, দাম, স্টক, ছবি, ভিডিও | অ্যাডমিন → Products |
| হিরো ব্যানার | অ্যাডমিন → Banners |
| ফ্রি ডেলিভারি অফার, প্রোমো কোড (কোডটা সাইটে কোথাও দেখা যায় না, শুধু সার্ভার যাচাই করে) | অ্যাডমিন → Offers |
| অর্ডার দেখা, স্ট্যাটাস বদল | অ্যাডমিন → Orders |
| দোকানের নাম, WhatsApp নম্বর, সোশ্যাল লিংক, মেনু, ক্যাটাগরি | `public/js/data.js` |
| রং ও ডিজাইন | `public/css/style.css` |

পণ্য ও অফার একবার ডাটাবেসে ঢুকলে `data.js` এর পণ্য তালিকা আর কাজে লাগে না। শুধু ওপরের শেষ তিন সারির জিনিস `data.js` থেকে আসে।

## ৫) জেনে রাখুন

- **ফ্রি সীমা:** Cloudflare Pages + D1 ছোট দোকানের জন্য যথেষ্ট। দাম ও সীমা বদলায়, তাই Cloudflare এর ওয়েবসাইটে মাঝে মাঝে দেখে নেবেন।
- **ছবি:** অ্যাডমিন থেকে আপলোড করা ছবি ব্রাউজারেই ছোট করে ডাটাবেসে রাখা হয়। শত শত ছবি হলে পরে Cloudflare R2 এ সরানো ভালো।
- **পাসওয়ার্ড ভুলে গেলে:** ইমেইল পাঠানোর ব্যবস্থা নেই। কাস্টমার ভুললে Owner অ্যাডমিন প্যানেলের Users ট্যাব থেকে অস্থায়ী পাসওয়ার্ড দিতে পারবেন। Owner নিজে ভুললে D1 Console এ `DELETE FROM users WHERE email='আপনার-ইমেইল';` চালিয়ে আবার সাইন আপ করুন (`OWNER_LOGIN` থাকায় আবার Owner হবেন)।
- **নিরাপত্তা:** পাসওয়ার্ড PBKDF2 দিয়ে হ্যাশ করা, লগইন কুকি HttpOnly, ভুল পাসওয়ার্ড বারবার দিলে সাময়িক বন্ধ, অর্ডারের দাম সার্ভারে নতুন করে হিসাব হয়।
- **অর্ডারের ইমেইল:** `data.js` এ `web3formsKey` দিলে নতুন অর্ডারের ইমেইলও যাবে। না দিলেও অর্ডার অ্যাডমিন প্যানেলে আসবে।
- **ব্যাকআপ:** মাঝে মাঝে D1 Console থেকে `orders` ও `users` টেবিল এক্সপোর্ট করে রাখুন।
- **অনলাইন পেমেন্ট** (বিকাশ/নগদ) এখনও যোগ হয়নি। এখন শুধু Cash on Delivery।

